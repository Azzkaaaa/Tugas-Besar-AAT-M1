\section{Hasil Auth dan Aggregator}
E2 memuat tiga login hosted UI dengan role berbeda, cookie HttpOnly yang tidak terbaca JavaScript, masa token 60 detik, CSRF, logout, refresh otomatis tanpa login ulang, penolakan token lama, expiry alami, serta persistensi sesi setelah restart bridge. Beberapa nama pemeriksaan memuat frasa \emph{before unfinished backend}; hal ini menegaskan cakupannya masih pengamanan di depan backend yang saat itu belum lengkap. Respons API bisnis yang belum tersedia tidak boleh dihitung sebagai keberhasilan integrasi data.

Contoh baris hasil E2 yang dapat ditelusuri dalam JSON:
\begin{lstlisting}
{"name": "automatic browser refresh without login", "passed": true}
{"name": "naturally expired bearer rejected", "passed": true}
{"name": "SQLite session survives container restart", "passed": true}
\end{lstlisting}

\section{Perintah Reproduksi}
Jalankan dari root repository kecuali diberi keterangan lain. Siapkan dependensi dan stack sebagaimana Bab 1. Jangan menganggap hasil \emph{skipped} sebagai lulus.

\textbf{Tes mock Docker.} Setelah kedua mock berjalan, skrip berikut memeriksa HTTP dan restart, lalu memulihkan kontrol PVMBG. Hasil baru menggantikan artefak cache, bukan salinan historis laporan.
\begin{lstlisting}
python tools/test_mock_containers.py --restart-check
\end{lstlisting}

\textbf{Tes unit Aggregator.} Jalankan dari \code{services/aggregator}; tidak membutuhkan stack bisnis penuh. Hasil JSON dapat disimpan sebagai bukti baru.
\begin{lstlisting}
go test -json ./internal/ingest ./internal/domain ./internal/auth
\end{lstlisting}

\textbf{Tes Auth lokal dan browser.} Tes lokal memerlukan dependensi Node workspace yang terpasang. Untuk browser gunakan stack Zitadel yang sesuai dan ikuti prasyarat pada panduan Auth.
\begin{lstlisting}
npx nx run auth-bridge:test
node tools/test_auth_browser.mjs
\end{lstlisting}

\textbf{Tes stack penuh.} Suite tidak menyalakan Docker secara otomatis. Setelah stack utama siap dan bootstrap menulis konfigurasi service user, aktifkan tes E2E pada PowerShell:
\begin{lstlisting}
$env:BNPB_E2E = "1"
python -m unittest discover -s tests -p "test_e2e_*.py" -v
Remove-Item Env:BNPB_E2E
\end{lstlisting}

Suite menguji jalur Envoy, token exchange, REST/gRPC, hazard dua sumber, SSE, webhook, serta notifikasi. Test tertentu dapat dilewati ketika data/prasyarat push belum tersedia; jumlah dan alasannya harus dicatat. Uji beban dan isolasi latensi mengikuti \code{docs/load-testing.md} dengan skrip \code{tests/load/aggregator.js} dan \code{tests/load/aggregator-isolation.js}.
